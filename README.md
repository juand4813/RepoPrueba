# Rueda · catálogo público de referencia

Vista temporal de solo lectura con 15 vehículos de muestra y datos tomados de avisos públicos. Este repositorio contiene únicamente los archivos estáticos del catálogo; no incluye ni se conecta a la base de datos local, cuentas, mensajes o formularios de publicación.

Los precios y fotos pueden cambiar o dejar de estar disponibles. El 3% es solo una referencia para ilustrar el cálculo de una posible comisión, no una oferta acordada.
